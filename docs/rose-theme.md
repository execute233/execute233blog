# 玫瑰墨色设计

当前博客采用玫瑰墨色：墨色背景、粉色强调、大圆角卡片和柔和侧影。首页包含个人档案、介绍、栏目入口、最近文章及学习记录；列表和阅读页沿用同一配色。

## 导航与页脚

- 桌面使用左侧悬浮导航，800px 及以下改用顶栏菜单。
- 搜索、设置位于右上角；顶部中央保留现有灵动岛。
- 页脚借鉴参考博客的三列结构，内容为站点介绍、栏目导航和社交入口。
- 栏目与社交链接来自 `src/config.ts`，页脚底部保留版权、备案、RSS 和 Sitemap。
- Logo 保持静态，灵动岛和自定义鼠标继续复用现有实现。

## 样式文件

| 文件 | 职责 |
| --- | --- |
| `src/styles/rose-theme.css` | 全站变量、页面外壳、列表及阅读页 |
| `src/styles/rose-home.css` | 首页布局、档案与内容卡片 |
| `src/styles/rose-navigation.css` | 顶栏、悬浮导航及其手机断点 |
| `src/styles/rose-footer.css` | 页脚与响应式列数 |

导航和页脚的断点规则各自放在对应文件，避免开发模式的样式加载顺序覆盖手机布局。默认色相位于 `siteConfig.themeColor.hue`，设置面板可调整并保存色相。卡片底色、边框、侧影与高亮由色相派生；博客背景色单独维护在 `src/data/appearance.ts`，保留用户选择。旧的卡片背景缓存不再应用。

## 阅读与页面跳转

- 正文最大宽度为 44rem，正文卡片减弱阴影和背景装饰。
- 1280px 及以上目录位于阅读页右侧，小屏幕改为正文上方的折叠目录。
- 每个页面都保留 `#toc`，满足 Swup 的容器替换要求。
- 导航依据替换后的文章栏目更新高亮，支持站内跳转、前进与后退。
- 页脚位于替换容器外，全站只渲染一份。
- 星空保留为低对比背景，设置中的“只看星空”仍可使用；减少动态效果时禁用装饰动效。
