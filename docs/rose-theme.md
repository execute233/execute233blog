# 玫瑰主题设计

当前博客采用玫瑰主题：暗色使用墨色背景与粉色强调，亮色使用粉白背景、深梅文字与玫红强调，共用大圆角卡片和柔和侧影。首页包含个人档案、介绍、栏目入口、最近文章及学习记录；列表和阅读页沿用同一配色。

## 主题切换与背景

- 右上角在搜索与设置之间提供主题按钮，点击或按 Enter、Space 按「亮色 → 暗色 → 跟随系统」循环；图标及提示说明当前选择和下一模式。
- 没有合法 `theme` 记录时默认跟随系统；保留已有 `light`、`dark`、`auto` 偏好。仅跟随系统时响应系统外观变化，首屏内联脚本在绘制前应用主题。
- `theme-tokens.css` 分别定义亮暗变量；亮色默认背景为 `#fff8fa`，暗色为 `#100d14`。代码块与首页代码区域继续使用深色背景。
- 外观设置使用 `execute233.appearance.v2`，保存共享 `hue` 和独立的 `backgrounds.light`、`backgrounds.dark`。旧 v1 的合法背景迁移到暗色，旧默认色更新为当前默认色，保留 v1 记录。
- 背景编辑作用于当前实际主题。切换时编辑器同步，恢复默认只重置当前主题背景和共享色相，不改变另一背景及主题选择。
- 存储不可用时仍能在当前会话切换和编辑；刷新后无法恢复未成功保存的设置。
- 亮色星空和樱花采用适合浅底的材质并降低强度，阅读页进一步减弱；暂停时切换主题仍会重绘一帧，「只看星空」只暂时增强当前主题。

## 导航与页脚

- 桌面使用左侧悬浮导航，800px 及以下改用顶栏菜单。
- 搜索、主题切换、设置位于右上角；顶部中央保留现有灵动岛，窄屏收窄折叠胶囊，避免新增按钮与其重叠。
- 页脚借鉴参考博客的三列结构，内容为站点介绍、栏目导航和社交入口。
- 栏目与社交链接来自 `src/config.ts`，页脚底部保留版权、备案、RSS 和 Sitemap。
- Logo 保持静态，灵动岛和自定义鼠标继续复用现有实现。

导航和页脚的断点规则各自放在对应文件，避免开发模式的样式加载顺序覆盖手机布局。默认色相位于 `siteConfig.themeColor.hue`，设置面板可调整并保存色相。卡片底色、边框、侧影与高亮由色相派生；博客背景色单独维护在 `src/data/appearance.ts`，保留用户选择。旧的卡片背景缓存不再应用。

## Tailwind 与样式入口

`Layout.astro` 导入 `src/styles/global.ts`，显式加载基础变量、Markdown、代码块、灯箱、滚动条、页面过渡和玫瑰主题。Tailwind 的基础样式与工具类仍由 `@astrojs/tailwind` 集成提供。`variables.styl` 保留 Markdown、按钮及明暗模式所需的基础变量，`theme-tokens.css` 提供玫瑰主题的覆盖值；两者都在使用。

图片组件只查找 Astro 支持的图片格式，支持 `src/assets/` 和文章目录中的相对图片。它不再通过扫描整个 `src` 间接加载样式及其他组件。首页与兴趣区的样式继续由对应页面或组件导入，灵动岛和光标也保留各自入口。

常规布局、间距、尺寸、文字、颜色和响应式优先使用 Tailwind。颜色及字号映射到现有 CSS 变量，不在 Tailwind 配置中重复定义数值。示例：`text-primary`、`text-muted`、`bg-surface`、`border-line`、`text-card-title`、`font-reading`、`font-code` 和 `rounded-card`。颜色变量包含完整颜色值；透明度效果继续使用 `color-mix()`，不直接使用 `bg-primary/50` 等透明度修饰符。

默认 `sm`、`md`、`lg`、`xl` 等断点保持不变。原有 CSS 的最大宽度条件对应 `max-360:`、`max-600:`、`max-640:`、`max-767:`、`max-800:`、`max-900:`、`max-1000:`、`max-1100:`、`max-1279:`，均包含边界值。它们通过 Tailwind 插件声明，避免混合原始媒体查询的 `screens` 配置禁用 Tailwind 的动态 `min-*`、`max-*` 变体。

迁移时保留实际数值，例如 `p-[26px]`，不改为近似的 `p-6`。同一属性迁移完成后删除对应 CSS 声明。脚本使用的类名、ID 和 `data-*` 属性继续保留。复杂动画、伪元素、遮罩和组件状态样式可以保留 CSS。阅读页的 `44rem !important` 与 Markdown 的 `!max-w-none` 暂时保留，后续迁移正文容器时一起处理。

基础整理同时修复两处加载顺序造成的差异：公共卡片统一保留 1px 边框，设置子菜单在 768px 及以上统一使用 `md:p-4` 的 16px 内边距，小屏幕保留两侧和底部 12px。关于页原先被重置掉的边框恢复后，页面总高度增加桌面 6px、手机 14px。这些差异经过前后截图确认并保留。工具页标题与下方内容之间仍为 16px，通过 `!mb-4` 明确覆盖列表标题的默认间距。

## 公共卡片

内容卡片使用 `src/components/ui/Card.astro`。它直接输出指定的 HTML 元素，内部内容通过默认插槽传入；标题、图标、标签、间距和响应式布局继续由具体卡片维护。公共样式由 `global.ts` 在全站加载，兼容仍使用 `card-base` 的正文、归档和设置浮层。

| 属性 | 默认值 | 用途 |
| --- | --- | --- |
| `as` | `div` | 根元素，可选 `div`、`article`、`section`、`a`；使用 `a` 时必须提供 `href` |
| `effect` | `none` | `none` 为静态，`highlight` 高亮边框和阴影，`lift` 额外上移 3px |
| `clip` | `false` | 是否裁剪超出圆角的内容 |

支持 `class`、`class:list` 和对应元素的常规 HTML 属性。内部链接保持独立；`effect` 只控制视觉反馈，不会改变点击范围或增加键盘停靠点。

```astro
---
import Card from "@components/ui/Card.astro";
import { url } from "@utils/url-utils";
---

<Card as="article" effect="highlight" class="profile-interest-card">
	<h3>兴趣</h3>
	<p>介绍内容。</p>
</Card>

<Card as="a" href={url("/blog/")} effect="lift" class="entry-card">
	<h3>博客</h3>
</Card>
```

档案、介绍、兴趣和技术卡片使用 `highlight`；栏目、学习、文章和有访问地址的工具卡片使用 `lift`，无地址的工具使用 `highlight`。档案、介绍、文章和工具通过 `clip` 保留原有裁剪行为。

悬停效果仅在支持精细指针和悬停的设备上启用。卡片自身或内部链接获得键盘可见焦点时，外壳高亮但不上浮，链接保留焦点轮廓；减少动态效果时取消位移和过渡，保留静态高亮。

## 字号与阅读层级

全站字体栈沿用参考站：`JetBrains Mono`、`Noto Sans SC`、`Microsoft YaHei` 及系统等宽字体回退。JetBrains Mono 使用用户提供的 1.0.3 版 WOFF2，放在 `public/fonts/jetbrains-mono/`，按需加载四种静态字重及斜体。此版本使用 Apache License 2.0，原始许可证和版权说明随字体保留，目录随 Git 提交。字体声明在 `src/components/FontFaces.astro`，URL 通过 `url()` 处理子路径部署。

参考站的正文使用独立的系统无衬线字体栈。本博客沿用这种区分，正文标题和代码使用 JetBrains Mono，长文段落使用系统无衬线字体。较新的参考站字体是可变字体；这里使用静态版本，未提供的字重由浏览器选择最接近的真实字重，不生成合成粗体或斜体。

字体栈集中在 `theme-tokens.css`：`--font-site` 用于全站界面与正文标题，`--font-reading` 用于文章段落，`--font-code` 用于代码及代码块标题。Tailwind 和代码高亮配置引用这些变量；页脚与普通标签继承全局字体。灵动岛保留独立的字体栈。

字号参考 `https://bad0rang3.xyz/`，按当前博客的页面和卡片角色对齐。共用字号在 `theme-tokens.css` 的 `--text-*` 变量中维护，首页大标题单独使用流式字号。

| 元素 | 桌面 | 手机（600px 及以下） |
| --- | --- | --- |
| 首页大标题 | 最大 85.6px | 随视口缩放，最小 44px |
| 页面标题 | 最大 60px | 30px |
| 文章及兴趣卡片标题 | 24px | 20px |
| 栏目标题 | 21.6–28.8px | 21.6px |
| 辅助标签 | 11.2px | 11.2px |
| 文章正文 | 16px，行高 1.8 | 16px，行高 1.78 |

以上数值以浏览器默认根字号 16px 为基准，使用 rem 的部分会随用户默认字号调整。手机不再通过根字号 14px 整体缩小文字；窄屏标题和操作入口允许换行。正文内的标题使用独立层级，避免被文章页的大标题样式覆盖。

## 樱花背景

全站背景在现有星空上叠加五瓣樱花和小花瓣，视觉参考 [Bad0RANG3 的樱花背景](https://github.com/Bad0RANG3/Bad0RANG3.github.io/blob/main/src/scripts/atmosphere.ts)。实现位于 `src/scripts/sakura.ts`，Canvas 在 `GalaxyBackground.astro` 中挂载，位于 Swup 替换容器之外。

- 花朵使用三组由主题色相派生的颜色，修改主题色时重绘缓存贴图，保留位置。
- 初始化时先测量内容边界、设置两侧遮罩并生成粒子，随后与星空在同一轮动画帧中首次绘制，不等待页面资源加载完成或浏览器空闲。首帧不推进粒子位置，之后按现有帧率播放；暂停状态下保留静态首帧。
- 樱花和小花瓣只在页面内容区两侧生成、循环下落；整层渐变遮罩让内容区完全透明，两侧柔和渐显。显示范围通过 `#main-grid` 的实际宽度计算，随窗口尺寸和内容布局调整；正文页进一步降低整体透明度。
- 宽度小于 768px 时隐藏樱花并停止绘制、释放 Canvas 像素缓冲，保留星空；恢复桌面宽度后自动恢复樱花。桌面花朵数量随两侧可见面积变化，最多 36 朵；Canvas 像素比上限 1.25，更新频率约 30 FPS，移动按实际经过的秒数计算。
- 现有“暂停动画”和“恢复默认”控制同时作用于星空和樱花；开启系统“减少动态效果”时樱花保持静态，后台标签页暂停绘制。
- “只看星空”预览暂时隐藏樱花，退出后恢复。

## 阅读与页面跳转

- 正文最大宽度为 44rem，正文卡片减弱阴影和背景装饰。
- 1280px 及以上目录位于阅读页右侧，小屏幕改为正文上方的折叠目录。
- 每个页面都保留 `#toc`，满足 Swup 的容器替换要求。
- 导航依据替换后的文章栏目更新高亮，支持站内跳转、前进与后退。
- 页脚位于替换容器外，全站只渲染一份。
- 星空保留为低对比背景，设置中的“只看星空”仍可使用；减少动态效果时禁用装饰动效。
